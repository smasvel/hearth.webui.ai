Model tests & automatic repair

Run chat, streaming, tool choices, typed arguments, file-tool contracts, long OpenCode build workflows, question/choice prompts, checkpoint resume, recovery from failures, large-code input, and context-limit checks. Question answers and tool results are simulated. Dependent steps stop if an earlier step fails. Models are tested sequentially; local loads unload other local chat models and leave the final local model loaded. Returned tools are inspected; no generated shell commands or changes to your projects are executed.

Download report

Automatic repair applies a reversible per-model tool-instruction profile, reruns failed checks, and keeps it only if results improve. It cannot retrain a model or repair arbitrary application code. Repairs affect Hearth requests and local compatibility proxies; clients connecting directly to remote servers need their own configuration. Reports keep the latest 30 runs. Use Reset repair on a model card to undo it.
