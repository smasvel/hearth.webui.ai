Assign an agent

Give an agent a project and target. It reads and edits real files, uses OpenCode tools, verifies progress, and continues unfinished work. Assignments run sequentially and survive closing this page or restarting Hearth. Questions and permissions appear here.

This OpenCode worker needs at least 16K context for its instructions and tools. Smaller configured models are disabled.

With a command, completion requires its successful exit. Without one, completion is agent-reported and includes its evidence. Commands run as your local account in the selected working directory; the folder is not a sandbox.

File edits are authorized by assignment. Otherwise shell commands wait for your approval. External-directory requests and loop warnings still require input.

If the cycle budget is reached or progress repeats three times, the task waits for review. Resume grants 50 more cycles when needed.
